<p>KNcloud is a modern and powerful proxy client for Android, supporting <a href="https://github.com/XTLS/Xray-core">Xray core</a> and <a href="https://github.com/v2fly/v2ray-core">v2fly core</a>.</p>

<h3>Features</h3>
<ul>
<li>Dual-mode UI: Simple Dashboard Mode and Classic List Mode</li>
<li>Cloud subscription management with traffic tracking</li>
<li>Comprehensive protocol support: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, TUIC</li>
<li>Smart routing and rules management</li>
</ul>

<h3>Usage</h3>

<h4>GeoIP and GeoSite</h4>
<ul>
<li><code>geoip.dat</code> and <code>geosite.dat</code> files are stored in the application assets directory</li>
<li>Enhanced geo rules can be automatically updated or manually imported</li>
</ul>
